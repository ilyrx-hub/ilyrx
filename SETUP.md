# IlyrX — Game, Mods & Download Hub

This version replaces the old hosting-style homepage with a dark gaming/mod community layout inspired by the information architecture of large mod platforms, while using original IlyrX styling and copy.

## Main sections
- Games
- Mods
- Collections
- Downloads
- Developer Hub
- Community
- Search
- Login / Sign Up

## Accounts
The login UI is prepared for Supabase Auth. Put the public project URL and anon/publishable key in `config.js`. Never put a service_role/secret key in the frontend.

Run `supabase.sql` in your Supabase SQL editor if the SQL file is present.

## Game links
The game pages use official/legal sources. Replace them only with URLs you are authorized to distribute or promote.

## GitHub Pages
Keep the relative paths intact so the site works at a repository URL such as:
`https://ilyrx-hub.github.io/ilyrx/`
