### Adding real downloads

Open the relevant HTML page and replace the demo `Download now` button URL with an official/legal download or store/release URL.

Do not host or distribute pirated copies, cracks, unauthorized installers, or copyrighted game files without permission.

The pages are relative-link friendly and work under GitHub Pages, including a repository path such as `/ilyrx/`.
